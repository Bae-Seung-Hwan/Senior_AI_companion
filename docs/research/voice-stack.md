### 벤치 실행

`tools/llm-bench/`에서 시나리오 12개(일상 대화, 사투리, 의료 질문, 할 일·취미 추출, 사기·응급 감지, 오탐 확인)를 모델별로 돌려요.

```powershell
cd tools/llm-bench
pip install -r requirements.txt
$env:ANTHROPIC_API_KEY = "sk-ant-..."
python bench.py --dry-run     # 호출 계획만 확인
python bench.py               # 실행 → results/<시각>.md 생성
```

결과 파일에 모델별 평균 지연과 턴당 비용이 나오고, 시나리오별 응답 옆에 `점수: _/5`를 직접 채우면 돼요.

### 결과 (2026-11-22, effort=low, 시나리오 12개 × 3모델)

| 모델 | 평균 첫 토큰(초) | 턴당 비용 (USD) | 1,000턴 (USD) | 사기·응급 감지 | 오탐 |
|---|---|---|---|---|---|
| Haiku 5.5 | **0.63** | **0.00008** | **0.08** | 3/3 | 없음 |
| Sonnet 5.5 | 0.76 | 0.00168 | 1.68 | 3/3 | 없음 |
| Opus 5.5 | 1.52 | 0.00443 | 4.43 | 3/3 | 없음 |

벤치의 시스템 프롬프트와 대화 이력은 짧아요. 실제 앱에서는 입력 토큰이 늘어나니 비용이 이보다 몇 배 커질 수 있어요.

**관찰**
- 세 모델 모두 존댓말, 공감, 2~3문장 길이, 의료 표현 금지(치매 단정 X → 병원·보건소 권유), 사투리 이해, 할 일 등록 제안을 잘 지켰어요
- 사기(가족 사칭, 코인)와 응급(낙상)은 모두 감지했고, 정상적인 용돈 이야기를 위험으로 잡은 경우도 없었어요
- Haiku 문제점:
  - "쑤시시는군요" 같은 존댓말 오류가 가끔 있어요
  - 등록 제안을 한 대화에서 반복해요 (손주 시험 대화에서 두 번)
  - "아침"을 `08:00`으로 마음대로 정해요
- Sonnet·Opus는 사용자를 "할머니, 할아버지"라고 불러요 → 호칭을 프롬프트에 넣어야 해요
- 관심사 추출은 모델과 상관없이 잡음이 섞여요 ("치과", "교회", "딸", "용돈"). Opus는 과거 취미인 "등산"을 빠뜨렸어요 → 모델 문제가 아니라 프롬프트에서 관심사를 명확히 정의해야 해요

**대화 품질 점수**: `results/*.md`를 어르신·팀원과 함께 읽고 채우기 (사람이 판단할 영역)

### 잠정 결론
- **대화와 정보 추출은 Haiku 5.5를 기본으로** 쓰기: 가장 빠르고 Sonnet보다 약 20배 싸요. 품질 차이는 프롬프트로 줄일 수 있는 수준이에요
- 하루 요약처럼 하루 한 번 돌고 품질이 중요한 작업은 Sonnet 5.5 검토
- 사기·응급 감지는 테스트 문장 3개로는 부족해요 → #25·#26에서 문장 100개로 다시 검증

**프롬프트 개선 할 일**
- 사용자 호칭 넣기 (예: "김영자 님")
- 등록 제안은 한 대화에서 한 번만
- 시간이 불분명하면 `null`로 두고 되묻기
- 관심사 = "지금 즐기는 취미·활동"으로 정의, 장소·가족·일정은 제외

## 5. STT 테스트 방법

1. 부모님·조부모님께 부탁해 아래 문장 10개를 녹음 (휴대폰 녹음 앱, 조용한 곳 5개 + TV 켜진 곳 5개)
   - "내일 오후 세 시 반에 치과 가야 해"
   - "혈압약 아침에 먹었어"
   - "아들이 급하게 돈이 필요하대"
   - 평소 말투(사투리 그대로)로 자유 발화 30초 2개
   - 약 이름 1개, 사람 이름 1개, 장소 이름 1개
2. 같은 파일을 후보마다 넣고 결과 텍스트를 표로 비교
3. 채점: 틀린 글자 수 / 전체 글자 수, **시간·숫자를 맞혔는지**는 따로 표시

| 샘플 | 정답 | 후보 A | 후보 B | 후보 C |
|---|---|---|---|---|
| 1 | 내일 오후 세 시 반에 치과 가야 해 | | | |

## 6. 턴당 원가 계산

```
턴당 원가 = STT(발화 초 × 초당 단가) + LLM(입력 토큰 × 단가 + 출력 토큰 × 단가) + TTS(글자 수 × 글자당 단가)
```

예시 가정: 발화 5초, 답변 80자, LLM 입력 1,500 토큰(시스템 프롬프트 + 최근 대화) / 출력 150 토큰

| LLM | LLM 턴당 원가 (가정 기준) |
|---|---|
| Haiku 5.5 | 약 $0.0002 |
| Sonnet 5.5 | 약 $0.0045 |
| Opus 5.5 | 약 $0.009 |

벤치 실측값(짧은 프롬프트 기준): Haiku $0.00008, Sonnet $0.0017, Opus $0.0044.

여기에 STT·TTS 단가를 더하면 하루 무료 대화 횟수를 정할 수 있어요. 실제 앱 프롬프트가 정해지면 다시 측정하세요.
