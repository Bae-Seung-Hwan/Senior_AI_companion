# 시니어 AI 동반자 (Senior AI Companion)

자산가 노년층의 하루를 기록하고, 가족과 이웃을 이어주며, 건강과 자산을 지켜주는 **음성 중심 AI 동반자 앱**입니다.
사용자와 AI의 대화가 모든 기능의 입력이 되고, 대화가 쌓일수록 요약·추천·이상 감지가 정교해집니다.

- **타깃**: 65세 이상 자산가 노년층 (보호자인 자녀는 결제자이자 2차 사용자)
- **핵심 가치**: 외로움 해소 · 가족의 안심 · 사기/건강 위험 보호 · 프리미엄 생활 편의
- **기획서**: [docs/시니어 AI 동반자 앱 기획서.pdf](docs/시니어%20AI%20동반자%20앱%20기획서.pdf)

## MVP (1단계)

모든 기능은 말로 입력하고 말로 들을 수 있어야 합니다.

| 기능 | 설명 | 담당 |
| --- | --- | --- |
| 음성 대화 | 대화 화면, STT·TTS, LLM 대화 API, 대화 기록 저장 | A |
| 오늘 한 일 요약 | 하루 끝에 한 일·만난 사람·기분을 3~5줄로 정리 | A |
| 할 일 추천 | 날씨·건강·취미·기분 기반 활동 제안 | A |
| 사기·응급 감지 | 위험 문장 감지, 경고 화면, 보호자 긴급 알림 호출 | A |
| 할 일 기록·복약 알림 | "내일 3시에 치과" 한 마디로 등록, 시간 되면 음성 알림 | B |
| 회원·보호자 연결 | 가입, 보호자 초대, 공유 범위 설정, 동의 기록 | B |
| 보호자 전송 | 요약본·긴급 알림을 자녀에게 알림톡/푸시로 전송 | B |
| 지역·취미 만남 | 근처 비슷한 취미의 소모임 매칭, 신고·차단 | B |
| 무료 등급·구독 | 요금제·결제, 인앱결제 검증, 사용량 관리 | B |

- **A (말벗 AI)**: 음성 대화 → 사기 감지 → 요약 → 추천
- **B (사람 연결)**: 회원·보호자 연결 → 할 일·복약 → 보호자 전송 → 모임 → 구독

첫 시연 목표: **"말로 할 일 등록 → 보호자가 요약 받기"**

A와 B가 주고받는 API는 [docs/api-contracts.md](docs/api-contracts.md)에 먼저 정의합니다.

## 로드맵

1. **MVP** — 핵심 기능 5개 + 복약 관리 + 사기 경고, 기본·프리미엄 구독
2. **확장** — AI 이어폰·음성증폭 번들, 지역·취미 만남 + 안전장치, 인지·기분 변화 감지
3. **프리미엄화** — 컨시어지 등급, 자서전 출판, 전문가·보청기 업체 제휴
4. **스마트글래스** — 플랫폼용 앱 출시, 안경점 제휴 번들

## 꼭 지킬 원칙

- **개인정보**: 대화·건강 정보는 민감정보. 보호자 공유는 항목별 별도 동의, 언제든 철회 가능
- **의료 표현 금지**: "치매 진단", "보청기" 대신 "변화 알림", "음성증폭" 등으로 표현
- **감시 느낌 피하기**: 보호자 전송 기본값은 간단한 요약, 상세 공유는 본인이 직접 켬
- **접근성 기본 사양**: 큰 글씨·큰 버튼, 느린 말하기 속도, 사투리 인식
